# projectiles

Parametric, 3D-printable projectiles for a 38.5 mm air-powered potato cannon.
Designs are OpenSCAD source files that generate STLs for Bambu Studio, printed in
PCTG.

- `designs/mk1/`: Mk1 Ducted-Tail Dart ([notes](designs/mk1/README.md))
- `designs/mk1w/`: Mk1-W Screaming Dart, with a death-whistle inside ([notes](designs/mk1w/README.md)). Rev B, based on the working whistle test
- `designs/whistle-tests/`: test pieces for the whistle core ([notes](designs/whistle-tests/README.md))
- `designs/fit-test/`: barrel fit-test rings ([notes](designs/fit-test/README.md))
- `tools/`: render, check, stability, and strength scripts
- `CLAUDE.md`: the design rules and decisions so far
